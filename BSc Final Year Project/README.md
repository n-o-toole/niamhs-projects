## Final Year Project for my BSc in Physics with Astrophysics.
### Project Title: Using the Wide-field Infrared Survey Explorer (WISE) to Identify Exceptional Planet Forming Disks

◦ Developed a Python-based data processing pipeline to query, clean, analyse, and visualise imagery and
catalogue data.
◦ Performed image processing and photometric analysis on multi-band infrared images (52 images).
◦ Extracted physical features from imagery and used them to identify and predict high-value targets for future
ESA observations.
◦ Worked independently on problem formulation, data validation, and result interpretation over a year-long
project.
◦ Communicated findings through a 42-page scientific thesis and oral presentations to academic staff and
peers.
