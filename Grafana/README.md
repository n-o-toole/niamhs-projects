# Weather Station Data Visualisation

Link -> https://ardentpantry2160.grafana.net/public-dashboards/2bdfe5a894e245d0a074acb4dfaa5d2e

This is my first project in Grafana where I have simulated data that might be collected by a weather station in Waterford, Ireland. 
The dashboard features graphs that display parameters such as cloud coverage, ambient humidity and temperature, wind speed, rain rate, seeing, Fried parameter,
sky temperature and irradiance, and wind rose.
